All code and data are in one anonymous repository: study-of-ai-scientists-in-SE. The results can be inspected in the browser without any setup.

Repository layout

├── orchestrator/     Docker sandbox and environment preflights
├── integrations/     one launcher per tool, the shared task prompt, token and cost metering
├── evaluation/       the evaluation pipeline and the LLM-judge prompts
├── docker/           Dockerfiles for the sandbox images
├── benchmark/
│   ├── tasks/              one directory per task (66 in total)

    ├── summary/      one row per run with every metric, plus the analysis scripts
    └── evaluations/  the full evaluation report of each run

Re-running the study

  
Requirements: a Linux host with Docker, Python 3.10 or later, and an OpenAI-compatible LLM endpoint. The README has the full instructions.


# 1. Place the task packages and build the sandbox images
mkdir -p ~/ai_scientist_inputs
cp -r benchmark/tasks/* ~/ai_scientist_inputs/
docker build -f docker/Dockerfile.base -t ai-scientist-base:20260615 docker/
cp benchmark_credentials.example.yaml benchmark_credentials.yaml   # fill in your keys

# 2. Run one tool on one task
TASK=~/ai_scientist_inputs/ASE-2025-004_predicting_recheck_success_in_continuous
python3 integrations/run_aris_task.py --task-dir $TASK --launch

# 3. Evaluate the run
python3 evaluation/run_evaluate.py \
  --run-dir  $TASK/workspace/<tool>_<timestamp> \
  --task-dir $TASK --axes all
