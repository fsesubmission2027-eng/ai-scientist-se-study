Token volume shows how far a run gets and how much it loops, not how efficient it is. The three leading tools differ by almost 2× in LLM calls (123 for ARIS, 202 for EvoScientist, 228 for DeepScientist) yet reach comparable composite scores. A single AI-Researcher run with 1,894 LLM calls used 1,146 M tokens and cost $27.68.
