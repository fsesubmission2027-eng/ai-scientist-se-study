From paper to task package

  1. Extract bibliographic metadata and key sections (Introduction, Experiment).
  2. Run automated and manual quality checks on the extracted content.
  3. Have an LLM rewrite the paper into a structured task: topic description, research questions, datasets, baselines, metrics, expected artifacts, difficulty.
  4. Export an independent package, supplemented with candidate baseline repositories and related-work citations.

Filtering criteria

CriterionA task is excluded whenRemoved
C1. Hardware and environmentIt needs irreplaceable hardware or an environment too complex to reproduce5
C2. Dataset and baseline availabilityThe core dataset is restricted or the baseline is not open source10
C3. Human subjectsThe experiment depends on human participants2
C4. ComputeThe task's own workload needs GPU compute or extra LLM API access15
